# Student-Journal

An AI-powered study management platform that helps students create personalized study plans, track assignments, analyze progress, and manage their academic journey efficiently.

## ✨ Features

- 📅 **Smart Study Planner** - AI-powered study plan generation with micro-task breakdown
- ✅ **Task Management** - Track daily study tasks with progress visualization
- 📝 **Assignment Tracker** - Manage assignments and deadlines
- 📊 **Analytics Dashboard** - Visualize study performance and progress
- 🔄 **Revision System** - Structured revision management
- 🌙 **Dark Mode** - Beautiful dark/light theme toggle
- 📱 **Fully Responsive** - Works perfectly on all devices
- 🔒 **Secure Auth** - User authentication and profile management

## 🚀 Tech Stack

- **Frontend:** React 18 + TypeScript + Vite
- **Styling:** TailwindCSS 3 + Radix UI
- **Backend:** Express.js
- **State Management:** React Query + Context API
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 📦 Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```

## 🌐 Deployment

This project is configured for easy deployment on Vercel:

1. Push to GitHub
2. Import project in Vercel
3. Deploy with default settings

4. Open your browser to the local server URL
5. Sign up to create an account and start planning!
